# Sofia Live Transport

Live map of Sofia's buses, trams, trolleybuses and metro (data: gtfs.sofiatraffic.bg).

Open it: https://flame-petrov.github.io/sofia-transport/

On a phone, use "Add to Home screen" to get an app icon.
